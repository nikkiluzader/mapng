What this is

MapNG reads OpenStreetMap to know where roads, buildings, rivers, forests and railways are. The public servers that hand out this data are often overloaded, so MapNG is making its own copy that it can serve by itself.

The build starts from the official planet file (a recent weekly snapshot, about 90 GB), cuts the world into about 800 blocks, and turns each block into small map tiles. Every block is built twice and kept only if both results are identical. This copy keeps every tagged object in OpenStreetMap, not only the parts MapNG draws today, so new features will not need a rebuild.

Built is not yet live. Built blocks are sitting on the build machine. They go live in MapNG after the build, together with an app update that reads them. Until then MapNG uses the smaller set outlined in blue on the map where it has one, and the public servers everywhere else.

The snapshot is a fixed point in time: edits made to OpenStreetMap after that date are not in it. Keeping the copy up to date with daily changes is planned for after the first full build.
